Redaxa for Linux

A Linux build of the Redaxa desktop app is planned, packaged as an AppImage, a .deb for Debian, Ubuntu and Linux Mint, and an .rpm for Fedora and openSUSE. It is not available yet and there is no release date. Join the waitlist and we'll email you when the first build is ready.

What the Linux app will do

The plan is the Windows app's feature set, on the same Redaxa account and plan:

  • Prompt checks with the findings and a redacted copy to review, including the Inspect clipboard button.
  • Your protected terms, such as client and project names, flagged in every check.
  • Repository reviews on your own machine, including accessible Git history and supported archives, with Pro or Business. Private repositories are not supported, as on Windows.
  • Sign-in kept in your desktop's keyring (GNOME Keyring or KWallet, through the Secret Service), the way the Windows app uses the Windows credential store, rather than in a plain file.

Some details may differ by distribution and desktop. We will list anything that works differently from Windows when the first build ships.

What works on Linux today

  • The web check runs in any browser: check a prompt or check a public GitHub repository with no install.
  • The Chrome extension installs from the Chrome Web Store in Chrome and Chromium-based browsers on Linux. It checks your message inside ChatGPT, Claude, Gemini and Perplexity before it sends, and its free checks run in your browser and send nothing.
