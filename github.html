What this check covers

Current files, readable binary strings, accessible Git history and branches/tags, commit messages, ZIP/gzip/tar contents, LFS objects and public GitHub submodules. No project code is executed. Binary scanning is not OCR or decompilation. Authentication failures, unsupported formats and limits are listed individually.

Budget: 10 minutes, 2 GiB inspected content, 64 MiB per decoded archive/LFS object, 4 nesting levels and 20 submodule snapshots. Unreachable Git objects cannot be inspected. No key is tested against its provider. This is an exposure review, not a complete code vulnerability audit.

Full repository scans run locally in Redaxa for Windows. Included with Pro and Business.
