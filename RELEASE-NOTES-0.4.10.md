Redaxa 0.4.10 cleans up after the PromptShield name.

- Installing or updating Redaxa removes a leftover "PromptShield" entry from Installed apps when the old PromptShield program is no longer on the computer. A PromptShield installation that still works is left as it is, and no app data is touched.
- The Windows download on the website starts the installer directly.

Windows installers require verified Aurelio Avila publisher signatures, trusted timestamps and compatible updater signatures before publication. Repository matches remain review candidates; no detector can guarantee zero false positives or prove that a credential is active.
