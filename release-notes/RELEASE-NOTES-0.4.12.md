Redaxa 0.4.12 makes repository checks much faster on large files and tightens account security.

- Repository checks finish quickly on files with thousands of matches, such as data exports and minified bundles. Line numbers and findings are unchanged, and when a report reaches its display limit, API keys and other credentials are listed before personal data.
- Some unusual text patterns no longer slow down a prompt check.
- Scan API keys now work only with the Scan API, as the API documentation describes.
- Signed-in web sessions accept requests only from Redaxa's own pages, and confirmation and reset emails only link back to Redaxa.
- The free daily allowance no longer stores network addresses. The privacy policy now describes automatic checks in the browser extension, the activity history kept for signed-in accounts, and every service involved.
- In audit exports, member addresses that a spreadsheet would treat as formulas open as plain text.

Windows installers require verified Aurelio Avila publisher signatures, trusted timestamps and compatible updater signatures before publication. Repository matches remain review candidates; no detector can guarantee zero false positives or prove that a credential is active.
