Redaxa 0.6.1 can receive updates from our own download server, dl.pctweaker.app, as well as from GitHub. Nothing changes in how you use the app.

- When Redaxa checks for a new version it asks dl.pctweaker.app first; if that server has nothing to offer, it asks GitHub exactly as before.
- An update is installed only when it carries Redaxa's update signature and the signed file name and version match the release on offer. It is accepted from the Redaxa release folder on dl.pctweaker.app or from the Redaxa release on GitHub, and from no other address.

Windows installers require verified Aurelio Avila publisher signatures, trusted timestamps and compatible updater signatures before publication.
