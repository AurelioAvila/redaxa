# Redaxa 0.3.3

Windows installers and the desktop application now carry an Authenticode signature issued to Aurelio Avila by Certum, with a trusted timestamp. Existing updater signatures are generated after packaging so automatic updates continue to verify correctly.

- Signed Windows setup and MSI packages.
- Consistent version numbers across the application and package metadata.
- Clearer English tray text describing AI privacy and prompt protection.

Windows reputation checks may still appear for a newly released application. Verify the publisher before installation; do not disable security protection.
