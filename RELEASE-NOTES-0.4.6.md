# Redaxa 0.4.6

A refined desktop workspace with clearer credential reviews and more consistent navigation.

- New workspace typography, integrated window controls and improved layouts for prompt and repository checks.
- Updated theme selection, early theme restoration and account loading states that avoid briefly showing signed-out controls.
- Clearer redaction previews and controls to show individual findings, a section or all findings.
- More conservative credential classification: explicit placeholders and unsigned JWT examples are separated; unattributed strings show their uncertainty.
- Finding priority and API notifications share the same confidence rules. Reports include detection confidence and provider-specific response guidance where supported.
- Existing account, support and trial eligibility fixes are preserved.

Repository scans require Pro or Business. Matches are candidates for review, not proof that a credential works or belongs to a particular account. No discovered credential is tested against its provider.
