What Redaxa detects

The Chrome extension, the web check and the Windows app share one engine. Each type below has its own page with real engine output, near misses and known false positives.

  • Personal data: email addresses, phone numbers, names after a greeting, English-format street addresses, IPv4 addresses, US Social Security numbers, UK National Insurance numbers and Italian fiscal codes.
  • Financial data: card numbers (Luhn-checked), IBANs (mod-97-checked) and crypto wallet addresses.
  • Credentials: API keys and tokens such as OpenAI, Anthropic, GitHub, Stripe and AWS, plus bearer tokens, JWTs, passwords, private keys and secrets in configuration.
  • Your own words: protected terms such as client and project names, which no generic pattern can know.

Limits

  • Detection can miss sensitive information or flag harmless text. A clean result means the checks found nothing, not that the text is safe.
  • A name is detected only after a greeting such as "Hi" or "Dear". Add the names that matter to you as protected terms.
  • Street addresses are recognised only in the English house-number-first format.
  • The phone rule also matches some order and invoice numbers.
  • Redaxa finds possible credentials; it never tests whether a key works. If a real key was already shared, rotate it: redacting a copy does not revoke it.

FAQ

Does Redaxa send my prompt to an AI provider?

No. Free checks in the Chrome extension run in your browser and the text stays on your device. Checks on the web, in the Windows app and with a Pro or Business plan run on Redaxa's servers: the text is sent over an encrypted connection, analyzed and discarded. It is not stored and not forwarded to an AI provider.

Does it change my prompt without asking?

No. You see what was found and a redacted copy. In the extension you choose to replace the message with the redacted version, send it anyway, or close the notice and edit it. On the web you copy the redacted version yourself.

Is it free?

Yes, for the basic checks. The Chrome extension's free checks have no daily limit and need no account. The web check and the Windows app give 5 free prompt checks a day without an account. Pro and Business remove the daily limit and add protected terms in the extension and team policies.

Will it find every piece of sensitive data?

No tool can promise that. Detection can miss sensitive information or flag harmless text, so read the redacted version before you send it.

Which AI chats does the extension work on?

ChatGPT, Claude, Gemini and Perplexity. For any other tool, check the text on the web or in the Windows app and paste the redacted copy.
